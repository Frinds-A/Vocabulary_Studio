# 词序 · Vocabulary Studio

一个 Windows 英语词汇学习桌面应用，当前版本 **1.2.5**。双击 `词序.exe` 即可使用，无需安装、无需注册；学习和发音完全离线，只有检查更新时需要联网。内置 **48** 本词书、共 **130,699** 条词汇，覆盖四六级、考研、出国、国内考试、通用核心词与专业英语。

**作者：Petrichor（GitHub：Frinds-A）· 独立开发**

学习记录保存在本机 `%LOCALAPPDATA%\词序桌面版\state.json`；把 exe 发给别人时，对方打开即是完整功能，互不影响。

## 直接使用

- 双击 `词序.exe`。
- 首次打开会看到今日计划、词库、生词本、学习统计与偏好设置。
- 在「我的词库」选择一本词书，点「开始学习」即可。
- 拼写练习页右上角的「全屏专注」会进入沉浸式拼写界面，按 `Esc` 或「退出」返回。
- 窗口支持最大化与还原，双击标题栏也可切换。
- 学习数据只写在本机；换电脑时可在「偏好设置 → 数据与备份」导出/导入 JSON。

> Windows 第一次运行未签名的个人软件时，可能出现「Windows 已保护你的电脑」。点「更多信息 → 仍要运行」即可；这是 SmartScreen 对未签名 exe 的常规提示。

## 界面与交互

- **配色**：参考 DSH 的白色界面体系，只使用黑白灰 —— 纯白主画布 `#FFFFFF`、浅灰侧栏 `#F9FAFB`、柔和炭灰文字 `#2A3038`、细边框 `#E4E7EC`，主操作与进度使用中性深灰 `#3A4048`。尽量减少大面积深黑块，全界面使用纯色块，不使用任何渐变。
- **英文与数字**：统一使用 Times New Roman；中文使用 Microsoft YaHei UI。
- **组件**：按钮、文本按钮、筛选 Chip、开关、进度条、搜索框和步进按钮使用 [material-components-qml](https://github.com/sudoevolve/material-components-qml) 的 Material 3 QML 组件；本地主题已改为黑白灰，来源与 LGPLv3 许可见 [NOTICE](desktop/qml/md3/NOTICE.md)。
- **动效**：页面切换的滑入淡入、切换单词时的淡入上移、卡片轻微抬升、数字滚动、进度条与图表生长、环形进度，均使用平滑缓动；不使用弹跳 / 回弹，避免过时的弹性感。
- **响应式**：最小窗口 1120 × 660；首页词库卡片会按宽度在 4 列 / 2 列间切换，词库页在窄窗口改为单列，练习页内容可滚动，不会裁切选项。

## 功能

- **今日计划**：可同时选择多本词书，按每日新词目标与到期复习自动组题；可选把生词本加入计划一起复习。首页只保留计划卡与词库卡，减少说明文字。
- **共享词条进度**：同一个单词如果出现在多本词书里，在任意一本中学习都会同步到所有包含它的词书；全局「累计掌握」按去重单词计数，词库卡仍按各自词书统计。
- **数据口径**：「今日新词」「已学」「已掌握」「待复习」分开统计；本周学习与累计学习按“单词 + 日期”去重，同一天重复作答只算一次，隔天再学再计一次；今日新词与待复习按当前选中的词书计算，切换选择立即同步；提交、切题、退出练习都会自动保存。
- **48 本词库**：在原有 4 本刘晓艳、2 本烤鸭TV、2 本 GPT 考研词书之外，新增 40 本 CSV 词书，按「考研 / 出国考试 / 国内考试 / 通用词汇 / 专业英语 / 人工智能」分类，共 130,699 条；词库页可按分类筛选。
- **键盘操作**：Esc 返回上一页/退出全屏，← → 上一词/下一词，Enter 判定或下一题，F11 全屏，Alt+K 提示首字母，Alt+A 显示答案，Alt+R 重新拼写，Alt+S 跳过，1–4 选择 A–D，Ctrl+H/L/P/B/T 和 Ctrl+, 切换页面，Ctrl+K 更换词库，Ctrl+Enter 开始学习，Ctrl+R 发音，Ctrl+D 收藏。鼠标悬停在按钮上会显示对应快捷键。
- **提示与引导**：拼写页可点「提示」或按 Alt+K 自动填写首字母；重写界面可点「忘记了」自动补全并显示答案；拼写、选择题、听音界面可点「显示答案」，拼写答案会直接填在短横线上，可继续点「重新拼写」，且不计入正确次数；首次启动显示使用说明，可勾选「下次不再弹出」，未勾选则每次启动都会显示，完整说明仍可在「偏好设置 → 使用说明」查看。
- **章节总览**：点任意词书先看到章节数与每章词数，可跳到任意章节；上次学到的章节会高亮，词表仍可按单词/释义/音标搜索。
- **三种练习**：拼写（看中文写英文）、选择题、听音拼写；单词和词组都支持这三种模式；拼写与听写共用逐字母短横线输入，支持 Enter 连续作答、上一词回退、跳过、收藏到生词本。练习页为全宽专注布局，顶部显示词书、章节和进度，底部显示时间、输入数、WPM、正确数和正确率。
- **章节与错题**：每章默认 20 词（可在设置改为 10/20/30/50），完成一章后可下一章或整章默写；答错自动进入错题本，可按错误次数复习。
- **输入体验**：可选轻微键盘音效；完成页显示正确率、WPM、用时和错题数；支持美/英音与慢/正常/快三档语速。
- **复习与备份**：统计页显示未来 7 天到期预测和近 30 天学习趋势；每天自动保留一份学习记录快照，最多 7 份。
- **词库管理**：48 本词库支持分类筛选、名称搜索和收藏，收藏可在词库页单独查看。
- **掌握判定**：每个词累计答对 **2 次** 才计入「已掌握」；拼错的词会先展示正确拼写和例句，再反复重写直到正确，重写过程不计入掌握、答题次数或正确率；词之后仍会在本轮后段再次出现，并标注「第 N 次出现」。正确和错误反馈都会给出例句，错误时额外给出正确拼写。
- **反馈排版**：反馈不再套一层红色卡片，而是用细分隔线、状态图标、正确拼写和例句来组织信息；拼错的字母会在「你的拼写」和顶部输入横线中用低饱和淡红圆角背景标出，正确字母保持弱化灰，避免刺眼的红绿对比；窄窗口提交后会自动滚动到反馈区。
- **沉浸拼写**：独立的全屏专注界面，与练习页共用逐字母短横线输入、当前字母光标呼吸、正确/错误即时反馈。
- **间隔复习**：1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天；顶部「待复习」可直接进入只含到期单词的复习；词书详情支持「重学词书」，将该书全部进度重置为未学。
- **生词本 / 熟词 / 学习统计**：生词本与熟词分栏查看；熟词是累计拼写正确 2 次的单词；本周柱状图按每天去重单词数统计，另有正确率环形图与各词库掌握度；设置以独立弹窗打开，使用说明收在弹窗左侧分类里。
- **本地发音**：答题后自动朗读（可在设置关闭），使用 Windows 系统语音；设置中可切换美式 / 英式发音，系统缺少对应口音时自动回退到可用的英语语音。
- **软件更新**：启动时可自动检查 GitHub Release，发现新版本会在软件内提示；下载完成后自动退出、替换 exe 并重启，不需要跳转 GitHub。可在「偏好设置 → 通用」关闭自动检查，仍可在「数据」页手动点「检查更新」。
- **数据备份**：完整学习记录的 JSON 导出与合并导入；支持导入自定义 PDF / Word(.docx) / TXT / CSV / JSON 词书；PDF 需含文本层，扫描版请先 OCR；自定义词书可在词库详情中删除。「设置 → 数据」提供一键格式化，清除全部学习记录但保留词书和设置。

## 开发者：从源码重新打包

需要 Python 3.12、PySide6 6.12、PyInstaller 6.x。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File desktop\build_exe.ps1
```

脚本会生成单文件 `词序.exe`（约 85 MB），并把 `qml/`、`assets/` 与 `data/vocabulary.json` 一并嵌入。只分发这一个 exe 即可。

源码结构：

```
desktop/
  app.py                 # 应用入口、窗口图标、字体
  backend.py             # 学习状态、间隔复习、TTS、备份
  qml/Main.qml           # 窗口壳、侧栏、标题栏、沉浸拼写
  qml/Theme.js           # 色彩 / 字体 / 词库主题 / 日期工具
  qml/pages/             # 六个页面
  qml/components/        # 按钮、卡片、进度条、开关等
  data/vocabulary.json   # 内置词库（22,067 条）
```

词库来源与许可说明见 [DATA_SOURCES.md](./DATA_SOURCES.md)。
