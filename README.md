# 词序 · Vocabulary Studio

一个 Windows 英语词汇学习桌面应用，当前版本 **1.4.2**。双击 `词序.exe` 即可使用，无需安装、无需注册。内置 **48** 本词书、共 **130,699** 条词汇，覆盖四六级、考研、出国考试、国内考试、通用核心词、专业英语与人工智能，适合从考试备考到专业课词汇学习。

[下载最新版](https://github.com/Frinds-A/Vocabulary_Studio/releases/latest)

**作者：Petrichor（GitHub：Frinds-A）· 独立开发**

学习记录保存在本机 `%LOCALAPPDATA%\词序桌面版\state.json`；把 exe 发给别人时，对方打开即是完整功能，互不影响。

> 词库、练习、统计和设置均可离线使用。真人发音首次获取需要联网，之后自动缓存在本机；检查更新需要联网。

## 直接使用

- 双击 `词序.exe`。
- 首页点「开始学习」，在弹窗里选择词书和章节，点击章节直接进入拼写。
- 点「继续学习」直接回到上次保存的进度。
- 首页右下角「范围」可切换：新词 + 复习、只学新词、只复习。
- 「我的词库」用于浏览全部词书：点击词书进入章节页，左侧选章节，右侧看该章单词。
- 练习页右上角可进入全屏专注；按 `Esc` 或右上角 `×` 退出并回到首页。
- 学习数据只写在本机；换电脑时可在「偏好设置 → 数据与备份」导出/导入 JSON。

> Windows 第一次运行未签名的个人软件时，可能出现「Windows 已保护你的电脑」。点「更多信息 → 仍要运行」即可；这是 SmartScreen 对未签名 exe 的常规提示。

## 界面与交互

- **配色**：黑白灰主界面，纯白主画布、浅灰侧栏、柔和炭灰文字、细边框；主操作与进度使用中性深灰，不使用渐变。
- **英文与数字**：统一使用 Times New Roman；中文使用 Microsoft YaHei UI。
- **布局**：首页负责今日计划、开始/继续学习和统计；词库页负责浏览词书与章节；学习向导用单个弹窗完成“选词书 + 选章节”，不再多跳一页。
- **动效**：页面滑入淡入、切换单词淡入上移、卡片轻微抬升、数字滚动、进度条与图表生长，均使用平滑缓动，不使用弹跳。
- **窗口**：最小 1120 × 660，支持最大化、还原、全屏专注和圆角窗口。

## 功能

- **首页学习向导**：点「开始学习」直接弹出词书 + 章节选择，左侧可搜索/切换 48 本词书，右侧点章节即开始拼写；不再经过词库页。
- **继续学习**：保存最近一次会话，点击后直接回到原单词和原进度，强制进入拼写模式。
- **最近词书**：向导默认选中上次学习的词书，常用词书不需要每次重新寻找。
- **学习范围**：首页「范围」下拉支持「新词 + 复习」「只学新词」「只复习」，从章节进入时按范围筛选本章单词。
- **词库浏览**：48 本词书支持分类筛选、名称搜索、收藏和自定义导入；点击词书进入双栏章节页，左侧章节列表，右侧当前章节单词，顶部为紧凑圆形搜索框。
- **章节完成状态**：章节完成后显示低饱和绿色圆形勾选；未开始、学习中保留灰色状态文字。
- **三种练习**：拼写（看中文写英文）、选择题、听音拼写；单词和词组都支持。练习页顶部可切换词书、章节、循环、美音/英音、发音、默写、跳过、上一词、提示、显示答案和下一题。
- **逐字母输入**：拼写与听写共用短横线输入，支持 Enter 连续作答、上一词回退、跳过；短语判定忽略空格，`a bill of fare` 与 `abilloffare` 都算正确。
- **反馈与重写**：拼错后展示正确拼写和例句，并要求照着答案重新拼写；重写过程不计入掌握、答题次数或正确率。拼错的字母用低饱和淡红圆角背景标出，避免刺眼红绿对比。
- **生词本**：答错**不会自动收录**，只有用户主动点击「生词 / 加入生词本」才会加入；生词本与熟词分栏查看，可按错误次数复习。
- **掌握判定**：每个词累计答对 **2 次** 才计入「已掌握」；同一个单词出现在多本词书时，学习进度会同步到所有包含它的词书。
- **间隔复习**：1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天；顶部「待复习」可直接进入只含到期单词的复习。
- **章节设置**：每章默认 20 词，可在设置中改为 10 / 20 / 30 / 50；完成一章后可继续下一章或整章默写。
- **真人发音**：优先使用在线真人发音，首次获取后缓存到 `%LOCALAPPDATA%\词序桌面版\audio`，之后同一单词可离线播放；支持美式/英式切换，网络不可用时回退到系统语音。
- **统计**：本周新词柱状图、综合正确率、词库掌握度；掌握度只展示 5 本词书，可点「选择词书」自行替换；「今日新词」按全部词书去重统计，与周图口径一致。
- **键盘操作**：Esc 返回/退出，← → 上一词/下一词，Enter 判定或下一题，F11 全屏，Alt+K 提示，Alt+A 显示答案，Alt+R 重新拼写，Alt+S 跳过，1–4 选择 A–D，Ctrl+H/L/P/B/T 切换页面，Ctrl+, 打开设置，Ctrl+Enter 开始学习，Ctrl+R 发音，Ctrl+D 收藏。
- **软件更新**：启动时可自动检查 GitHub Release，发现新版本会在软件内提示；下载完成后自动退出、替换 exe 并重启。可在「偏好设置 → 通用」关闭自动检查。
- **数据备份**：完整学习记录 JSON 导出与合并导入；支持导入自定义 PDF / Word(.docx) / TXT / CSV / JSON 词书；PDF 需含文本层，扫描版请先 OCR；自定义词书可删除；「设置 → 数据」支持一键格式化。

## 开发者：从源码重新打包

需要 Python 3.12、PySide6 6.12、PyInstaller 6.x。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File desktop\build_exe.ps1
```

脚本会生成单文件 `词序.exe`（约 85 MB），并把 `qml/`、`assets/` 与 `data/vocabulary.json` 一并嵌入。只分发这一个 exe 即可。

源码结构：

```
desktop/
  app.py                 # 应用入口、窗口图标、字体
  backend.py             # 学习状态、间隔复习、发音、备份
  qml/Main.qml           # 窗口壳、侧栏、标题栏、沉浸拼写
  qml/Theme.js           # 色彩 / 字体 / 词库主题 / 日期工具
  qml/pages/             # 首页、词库、章节、练习、生词本、统计、设置
  qml/components/        # 按钮、卡片、进度条、开关、学习向导
  data/vocabulary.json   # 内置词库（130,699 条）
```

词库来源与许可说明见 [DATA_SOURCES.md](./DATA_SOURCES.md)。
